# Cartograph

A declarative capture engine for what an organisation has decided to
do: goals, programmes, projects, operations, KPIs and the data sources
behind them, as manifests in a directory, validated against a contract,
rendered as documents. Apache License 2.0.

| Repository | What |
|---|---|
| [cartograph-engine](https://github.com/ProjectCartograph/cartograph-engine) | The engine, the contract, the command line, the public Go packages (`pkg/client`, `pkg/merge`, `pkg/uiconformance`) |
| [cartograph-ui](https://github.com/ProjectCartograph/cartograph-ui) | The web interface, and the terminal interface as it is built |

Start with `docs/ARCHITECTURE.md` in the engine. Contributions follow
each repository's `CONTRIBUTING.md`; agents read `AGENTS.md`.
